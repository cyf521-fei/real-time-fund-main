# 实时基金估值系统 v2.0

## 项目概述
这是一个实时基金估值系统，能够显示基金的实时估算净值和趋势图。

## 功能特性
- 实时基金净值估算
- 趋势图可视化
- 支持多个基金代码查询
- 响应式设计

## 技术栈
- Next.js
- React
- JavaScript
- CSS

## 本地开发
1. 确保已安装 Node.js
2. 运行 `npm install` 安装依赖
3. 运行 `npm run dev` 启动开发服务器
